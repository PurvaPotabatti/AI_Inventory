ShopStream Reactive Commerce Advisor

The backend is running on port 8080.

You can test the API endpoints using tools like Postman or curl.

Example endpoints:

  • GET http://localhost:8080/api/products - Get all products
  • POST http://localhost:8080/api/products/{id}/orders - Simulate sale
  • PATCH http://localhost:8080/api/products/{id}/stock - Update stock
  • GET http://localhost:8080/api/suggestions/pricing - Get pricing suggestions
  • GET http://localhost:8080/api/suggestions/reorder - Get reorder suggestions

The agentic recommendation loop is working - when you simulate sales or update stock levels, suggestions will automatically be generated and appear in the suggestions endpoints.
